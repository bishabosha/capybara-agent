## Step 1: generate the skill IDE workspace

```sh
./mill run skill-ide --skill skills/coding
```

`SkillIde.prepare` writes `.agent-runtime/SkillPreview.scala` and runs:

```text
scala setup-ide <skill-directory> <generated-preview>
  <builtin-interface> <builtin-implementation>
  --workspace <skill-directory> --scala 3.10.0
  --scalac-option=-preview
```

Open the skill directory in Metals or import its BSP project in IntelliJ. Edit the original files. Regenerate the workspace when dependency directives change.
